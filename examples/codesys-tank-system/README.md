# CODESYS Tank System Example

Generator Mode: Full Project Pack
Platform: CODESYS V3

Scope:

- Fill valve.
- Transfer pump.
- Level transmitter.
- High-high and low-low level protection.

Expected outputs:

- `GVL`, `DUT`, `FB_SequenceEngine`, `FB_Alarms`, `PRG_Main`.
- Persistent retained step word.
- PLCopen XML or `.export` when import-ready output is required.
- CODESYS visualization tag list.

Validation:

- Retain behavior check.
- Level scaling check.
- Valve/pump interlock test.
