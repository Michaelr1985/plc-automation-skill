# Siemens Pump Station Example

Generator Mode: Full Project Pack
Platform: Siemens S7-1200/S7-1500
Software: TIA Portal

Scope:

- Two duty/standby pumps.
- One flow meter.
- One tank low-level dry-run input.
- Siemens HMI and optional WinCC SCADA.

Expected outputs:

- Siemens DB design.
- Pump FBs with instance DBs.
- Retained step engine.
- IO list.
- Alarm list.
- Cause/effect matrix.
- FAT/SAT workbook.
- Test harness.

Validation:

- TIA source wrapper checks.
- Reset-does-not-start test.
- Pump failover test.
